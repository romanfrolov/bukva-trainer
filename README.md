# Буква

Тренажёр по 43 словарным словам для 6 класса. Слово считается выученным после одного верного ответа в карточках и двух верных ответов подряд в каждом из двух письменных режимов, «Пропущенные буквы» и «Диктант». Ошибка сбрасывает серию только для этого слова в текущем письменном режиме.

Блок «Прогресс» показывает общее число слов и число слов с зачётом в каждом режиме. Счётчики обновляются после проверок и загрузки сохранённых результатов.

«Пропущенные буквы» открываются для слова после зачёта в карточках. Для допуска к диктанту дополнительно нужны два верных ответа подряд в пропусках. В каждом режиме «Все слова» показывает все доступные слова. В «Пропущенных буквах» вариант «Только невыученные» показывает доступные слова, у которых ещё нет двух верных ответов подряд в пропусках. В карточках и диктанте этот вариант показывает доступные слова, по которым ещё не набраны все зачёты.

При смене режима или списка слов начинается новый круг. В тренировке одного слова оно остаётся выбранным, когда доступно в новом режиме.

На iPhone откройте сайт в Safari. Для быстрого доступа выберите «Поделиться» → «На экран “Домой”». Для диктанта браузеру нужен русский голос.

Прогресс сохраняется в браузере. Чтобы перенести его с другого устройства или из локальной версии тренажёра, сохраните там файл результатов и нажмите «Загрузить результаты» в открытом на iPhone тренажёре. Файлы с раздельным учётом восстанавливают зачёты по всем трём режимам. Самые ранние файлы содержат только общий результат. Если прежнее обновление уже обнулило письменные зачёты, загрузите файл, сохранённый до обнуления.

В восстановленном круге письменного режима тренажёр пропустит оставшиеся слова, которые ещё недоступны для этой проверки. Уже полученные зачёты сохраняются.

Для публикации в GitHub Pages выберите `Settings` → `Pages` → `Deploy from a branch`, затем ветку `main` и папку `/(root)`.
