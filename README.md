# Буква

Тренажёр по 27 словарным словам для 6 класса. В нём есть карточки, задания на пропущенные буквы и диктант. Слово засчитывается после одного верного ответа в карточках, двух в пропусках и двух в диктанте.

На iPhone откройте сайт в Safari. Для быстрого доступа выберите «Поделиться» → «На экран “Домой”». Для диктанта браузеру нужен русский голос.

Прогресс сохраняется в браузере. Чтобы перенести его с другого устройства или из локальной версии тренажёра, сохраните там файл результатов и нажмите «Загрузить результаты» в открытом на iPhone тренажёре.

Для публикации в GitHub Pages выберите `Settings` → `Pages` → `Deploy from a branch`, затем ветку `main` и папку `/(root)`.
